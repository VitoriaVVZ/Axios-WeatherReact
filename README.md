# React + Vite

Aplicação desenvolvida em React para consulta de previsão do tempo em tempo real, consumindo dados da API do OpenWeather através do Axios.

##  Tecnologias Utilizadas

- **React**
- **Axios** (requisições HTTP)
- **OpenWeather API** (dados meteorológicos)
- **CSS3 / JavaScript**

##  Como executar o projeto localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/VitoriaVVZ/Axios-WeatherReact.git](https://github.com/VitoriaVVZ/Axios-WeatherReact.git)
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Axios-WeatherReact
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Configure a variável de ambiente:**
   Crie um arquivo `.env` na raiz do projeto e adicione sua chave da API do OpenWeather:
   ```env
   VITE_API_KEY=sua_chave_aqui
   ```
   
5. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
